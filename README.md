# NAND2TETRIS__LAB
# Hack Computer Capstone – Make the Computer Draw a Box

A Nand2Tetris-based capstone project that demonstrates the working of the Hack Computer architecture.

### Features
- Implementation of CPU, Memory, and Computer HDL chips.
- Python-based two-pass Hack Assembler.
- Symbol and variable address management using `symbols.txt`.
- Custom Hack Assembly program (`Box.asm`) to draw a black rectangle on the screen while a key is pressed.
- Personalized box dimensions based on student roll number.

### Personal Configuration
- **Roll Number:** 2501010133
- **K:** 33
- **Box Position:** Row 33
- **Box Dimensions:** 32 × 20 pixels
- **Assembler Extra Feature:** Symbol table generation.

### Technologies
- Hack HDL
- Python
- Hack Assembly
- Nand2Tetris Hardware Simulator and CPU Emulator
